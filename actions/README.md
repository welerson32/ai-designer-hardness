# Actions do Photoshop

Actions nativas acionadas pela receita `play-action` (`set`, `action`). Regras em `.claude/policies/execucao-lotes.md`.

- Exportar o set: painel Actions → Save Actions → `actions/<set>.atn` (versionado).
- Importar numa máquina nova: painel Actions → Load Actions.
- Gravar **sem diálogos modais**.
